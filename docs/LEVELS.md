# 关卡设计与可验证顺序

熟度统一用 **0–12 整数刻度**。每拍（回合）只能选一次主要操作：把一团面移进温箱、移到凉架或送进炉；调温箱档位是辅助操作，不占主要操作次数。

## 通用结算规则

每拍按固定顺序结算，事件流在「模拟这一拍」浮层里逐行显示：

1. **换位**：执行主要操作（或空拍）。刚换位的面团在**目的地**参与本拍后续结算。
2. **烤炉**：炉中面团占炉倒数 −1；归零立即交单。炉内熟度**冻结**，不参与温箱/凉架变化。
3. **温箱**：同一档位给箱内每个槽位的面团 `+档位值`（0 档 = +0，可保温）。
4. **凉架**：架上面团统一 `+1`（比温箱慢）。
5. 案板上的面团熟度不变。

交单判定优先级：先看熟度窗口，再看截止回合。

| 反馈 | 条件 |
| --- | --- |
| `success` 成功 | 熟度在窗口闭区间内，且交单拍 ≤ 截止回合 |
| `early` 夹生退单 | 熟度 < 窗口下限（即使已超截止，窗口判定也优先） |
| `late` 烤过退单 | 熟度 > 窗口上限 |
| `overdue` 超时退单 | 熟度合格，但交单拍 > 截止回合 |

入炉拍记为 E，占炉 N=2 拍，则交单拍 = E + N − 1（入炉拍冻结、下一拍打点交单）。
最晚入炉拍 = 截止回合 − N + 1。

退单只标记该团为 `failed` 并写入交单记录，**不会清空或改动其他面团**的熟度与位置。

## 第一关 · 熟悉温箱

温箱 2 槽、档位 0/1/2；凉架 +1；烤炉占 2 拍。

| 面团 | 初始熟度 | 合格窗口 | 截止回合 |
| --- | --- | --- | --- |
| A | 2 | [5, 6] | 9 |
| B | 1 | [7, 9] | 10 |
| C | 3 | [6, 7] | 8 |

教学点：温箱档位是全局的，同槽位的面团共享火力；想让不同面团以不同速度成熟，要靠**时间错开**和 0 档保温，而不是同箱不同速。

### 通关顺序（`npm test` 中 `L1_WIN` 逐步断言）

| 拍 | 档位 | 主要操作 | 拍末熟度 (A/B/C) | 交单 |
| --- | --- | --- | --- | --- |
| T1 | 1 | A → 温箱 | 3 / 1 / 3 | |
| T2 | 2 | C → 温箱 | 5 / 1 / 5 | |
| T3 | 2 | A → 烤炉（冻 5，剩 1） | 5 / 1 / 7 | |
| T4 | 0 | B → 温箱（0 档保温，C 不涨） | 5 / 1 / 7 | **A=5 成功@4** |
| T5 | 2 | C → 烤炉（冻 7） | 5 / 3 / 7 | |
| T6 | 2 | 空拍 | 5 / 5 / 7 | **C=7 成功@6**（窗口上沿） |
| T7 | 2 | 空拍 | 5 / 7 / 7 | |
| T8 | 2 | B → 烤炉（冻 7） | 5 / 7 / 7 | |
| T9 | – | 空拍 | – | **B=7 成功@9** |

边界要点：C 在 T2 末熟度 5、T3 末到 7（窗口 [6,7] 上沿），T4 用 0 档把它稳在 7，T5 入炉冻结。

### 反例（几乎成功，差 1 刻度）

C 贪温箱多留一拍：T1 进 2 档箱 (3→5)，T2 空拍 (→7)，**T3 再空拍 (→9)**，T4 入炉，T5 交单。

- 熟度 9 > 窗口上限 7 → `late` 烤过退单（测试断言 `result: 'late', doneness: 9, turn: 5`）。
- 若 T3 改为入炉，则 T4 交单熟度 7，正好合格——这就是窗口上沿的边界。

## 第二关 · 烤炉撞单

烤炉一次一团、占 2 拍，三张订单截止回合互相咬住。温箱仍为 2 槽。

| 面团 | 初始熟度 | 合格窗口 | 截止回合 | 最晚入炉拍 |
| --- | --- | --- | --- | --- |
| A | 1 | [4, 5] | 6 | 5 |
| B | 4 | [7, 9] | 9 | 8 |
| C | 2 | [6, 8] | 10 | 9 |

教学点：按截止回合排 EDF 顺序 A → B → C；温箱槽位只有 2 个，A 出箱后 C 才有位置；C 改走凉架慢速线，档期正好接住 B 腾出的炉。

### 通关顺序（`npm test` 中 `L2_FINAL` 逐步断言）

| 拍 | 档位 | 主要操作 | 拍末熟度 (A/B/C) | 交单 |
| --- | --- | --- | --- | --- |
| T1 | 1 | A → 温箱 | 2 / 4 / 2 | |
| T2 | 1 | B → 温箱 | 3 / 5 / 2 | |
| T3 | 1 | 空拍（养熟 A） | 4 / 6 / 2 | |
| T4 | 1 | A → 烤炉（冻 4），腾出箱槽 | 4 / 7 / 2 | |
| T5 | 1 | C → 凉架 | 4 / 8 / 3 | **A=4 成功@5** |
| T6 | 1 | B → 烤炉（冻 8），腾出箱槽 | 4 / 8 / 4 | |
| T7 | – | 空拍 | 4 / 8 / 5 | **B=8 成功@7** |
| T8 | – | 空拍（C 在凉架养到 6） | 4 / 8 / 6 | |
| T9 | – | C → 烤炉（冻 6） | 4 / 8 / 6 | |
| T10 | – | 空拍 | – | **C=6 成功@10**（窗口下沿） |

关键时序：T9 是**先换位后结算**，C 在 T8 末熟度 6，T9 入炉时冻结为 6；凉架的 +1 在换位之后才结算，入炉吃不到，所以不能晚到 T9 才涨到 6。

### 反例一（夹生，太早）

A 只在温箱待一拍（T1 末熟度 2），T2 就抢入炉，T3 交单熟度 2 < 窗口下限 4 → `early` 夹生退单（测试断言 `doneness: 2, turn: 3`）。

### 反例二（撞单，B 抢炉）

T3 让 B 抢先入炉（此时 B 熟度仅 5），T4 B 交单熟度 5 < 窗口下限 7 → B 自己先 `early` 退单；A 被挤在温箱，档期整体后移。一次失败后 A、C 的状态全部保留。

### 截止回合边界（overdue 独立反馈）

把 A 养到熟度 4（合格）后用 0 档温箱保温，只拖入炉时间：

- T5 入炉 → T6 交单（= 截止 6）：`success`，边界准时。
- T6 入炉 → T7 交单（> 截止 6）：熟度仍合格，反馈为 `overdue` 超时退单。

## 自动化核对

- `npm test`：17 个用例，覆盖两关通关/反例、四种交单反馈、结算事件顺序、槽位与炉位互斥、炉内冻结、撤销快照、模拟不落状态、赶单分析。
- 赶单分析（右侧订单面板徽标）：`赶得上 / 档期紧张 / 已赶不上`，其中最晚入炉拍 = 截止 − 占炉 + 1；熟度一旦超过窗口上限立即判 `已赶不上`（熟度只涨不跌）。
