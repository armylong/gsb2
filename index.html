裁决规则（两条路径共用）
  1. 只接受 t ≥ 0 的命中。
  2. 射线起点在该物件内部时，该物件记为 t = 0 且标记 inside。
  3. 按 t 升序；距离差 ≤ 1e-4 视为并列。
  4. 并列时按物件 id 升序，id 小者胜出；与遍历顺序、分组方式、分组上限无关。

分组上限 = 每个叶组最多装多少件物件。上限越小分组越细，候选越少， 但需要测试的节点和分组更多；上限越大则相反。

同一批射线核查

固定一批射线（4 条演示射线 + 200 条确定性随机射线，含空中起点、物件内部起点、 瞄准中心的射线），在每个分组上限下分别用加速路径与逐件求交，逐条比对选中结果。 射线批次在场景重建时固定，变换物件后仍复用同一批。
